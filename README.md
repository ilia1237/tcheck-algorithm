# 🌡️ TCheck Algorithm

Навчальний проєкт з алгоритмізації та програмування.

## 📌 Опис

Проєкт демонструє алгоритм перевірки поточної температури
та керування системою охолодження.

## ⚙️ Принцип роботи

Програма порівнює поточну температуру `tc`
із заданою температурою `tb`.

Якщо:

`tc >= tb`

виконується один алгоритм роботи.

Якщо:

`tc < tb`

виконується інший алгоритм.
